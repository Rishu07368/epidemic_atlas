# Changelog

## 1.0.0 — initial educational release

- Added frequency-dependent SIR with RK4 and validated parameters.
- Added a rectangular spatial SIR model with local RK4 reaction and conservative four-neighbour exchange.
- Added computed heatmaps, cell inspection, Laplacian explanation, playback controls, and three-model infection-curve comparison.
- Added versioned scenario Properties files, CSV exports, JUnit 5 tests, Maven build, and Windows packaging/CI definitions.
- Documented model conventions, numerical splitting/stability, assumptions, and limitations.
- Not included: geographic data, stochastic models, heterogeneous parameter maps, multiple infection zones, PDF reports, or a published release.
