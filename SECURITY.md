# Security

Epidemic Atlas is a local desktop application. It has no network client, server, authentication, database, external map content, or telemetry. Scenario and export files are created only at user-selected paths. Scenario files are Java Properties text; loading a scenario validates its format version and parameter values before creating a model.

Do not open untrusted files using unrelated applications or run packages from untrusted sources. Download releases only from the project's verified GitHub repository and check SHA-256 values published alongside them. Unsigned Windows packages may trigger SmartScreen warnings.

Report a suspected vulnerability privately to the repository maintainers before public disclosure. Do not include personal or sensitive data in a report. No security response SLA is currently established for this initial project.
